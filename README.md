# Devil n Dove Website

Official website for **Devil n Dove**.

This site supports:

- public website
- members area
- admin management
- workshop inventory
- featured creations
- future online store

---

# Tech Stack

Frontend

- HTML
- CSS
- Vanilla JavaScript

Backend

- Cloudflare Pages Functions

Database

- Cloudflare D1 (SQLite)

Storage

- Cloudflare R2

---

# Features

Public site:

- Gallery
- Creations
- Tools
- Supplies

Members:

- login/logout
- password change
- session management

Admin:

- dashboard summary
- user management
- session cleanup
- password reset
- user deletion
