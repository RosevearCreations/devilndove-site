Account help

Use this page if you forgot your password or are not sure which email is tied to your account. For privacy, requests are logged and reviewed without confirming whether an account exists.

Forgot password

Enter the email registered to your Devil n Dove account. If eligible, we will send a private one-time reset link, valid for 30 minutes.

If you no longer have access to the registered email, use the account help form beside this one. For security, we cannot email a reset token to an unverified alternate address.

Forgot account / email

Unsure which email we used? Submit a secure account recovery request for staff review. We never reveal whether an account exists or send a password to a different address.

Set a new password

Use the private link received by email. It can be used once, and expires 30 minutes after the request. All existing sessions will be signed out.

What happens next

  • Password resets are emailed only to the original registered address, if email delivery is configured.
  • Forgot-account support requests are stored for staff review.
  • The site does not reveal whether a matching account exists.
  • You can still create a new account later if needed.
