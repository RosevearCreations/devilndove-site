How a custom request moves forward

The same customer-safe journey is used from the first request through the private order-status page. Nothing becomes an automatic order, stock reservation, provider send, or public post.

  1. 1. RequestYou send the idea, recipient/occasion, timing, budget, handoff preference, and optional private reference images.
  2. 2. Review & proofWe review fit, materials, references, gift details, availability, and anything that needs clarification.
  3. 3. QuoteA reviewed private quote is prepared before payment or making.
  4. 4. MakingAccepted work moves through planning, making, curing/finishing, and quality review.
  5. 5. Pickup / shipping / event handoffWe use the reviewed local pickup or Canada-only shipping plan. Event/market notes are not a stock reservation until availability is revalidated live.
  6. 6. CompleteThe private status page closes the customer journey; any review/photo permission remains a separate explicit choice.
