Production Calendar, Resource Conflicts & Availability

Schedule project work, mark maintenance, reserve shared tools and record deadlines using actual UTC time windows. Conflicts are checked against canonical saved bookings, including across projects.

ⓘ Help — recorded conflicts and physical availability

Only human-confirmed calendar entries constitute booking evidence. No recorded overlap means no conflicting entry in this application; it does not prove a machine is powered on, maintained, physically available or that someone else isn't using it. Resource capacity is one booking per active Inventory tool or workstation at a time. A project deadline records a delivery target, not a resource reservation.

A real maintenance entry blocks overlapping bookings. A deliberate scheduling override requires an explanation; overriding maintenance requires a separate acknowledgement. Changes preserve prior history by cancelling and creating a new entry. There is no automatic maintenance sign-off, work order completion, inventory consumption, or customer notification.
