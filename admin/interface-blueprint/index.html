The future Product Entry flow

All Product facts stay in one saved record. Choosing a destination never silently publishes anything.

1

Details

Name, SKU, category, CAD price, stock and description; show required fields beside the field itself.

2

Recipe

Choose saved soap base, scent and added oil. Generate label ingredients only from authentic verified source records; owner confirms the actual batch.

3

Photos

One shared gallery of real Product images. Each photo carries rights approval, descriptive alt text, file provenance and optional destination eligibility.

4

Destinations

Clearly separate Save Product, Create draft, Update existing draft, Prepare manual handoff and Publish.

Rules for future Admin screens

The reference uses a compact top bar, contextual side rail, dark navy surfaces, rounded cards, purple primary actions, gold/copper accents, semantic status colours and source-backed numbers. These styles are opt-in and will be introduced only on Admin surfaces that actually need a revamp.

Publishing safety and recovery rules
  • Local Save Product never creates or publishes remote content.
  • Every destination shows account, readiness, required fields, operation status and remote ID when confirmed.
  • Never create a duplicate Etsy draft while an existing listing ID is unknown or unverified.
  • Each uncertain remote write must be reconciled by readback before offering a retry.
  • Photo permission, source, alt text and exact uploaded-image receipts are independently checked.
  • No direct posting is claimed for a provider without tested and authorized capability.
Responsive and accessibility rules
  • Desktop: top navigation, contextual rail and readable multi-column cards.
  • Tablet: stack secondary panels; allow navigation wrapping without clipped labels.
  • Mobile: single-column work areas and cards; local scrolling for larger tables.
  • Visible focus, meaningful labels, source timestamps, loading/error/empty states and keyboard-operable actions.
