Storefront merchandising

Editable Home carousel

Create and preview drafts, set display order and schedules, then publish deliberately. A saved draft never appears publicly. If the schema, API, slide list or first image is unavailable, Home keeps its existing static hero.

Feature contract and safety boundary

Owner and purpose

Commerce/merchandising owns approved copy, imagery and same-site destinations. The carousel highlights current creations and stories without changing product availability.

Public behavior

Responsive media, previous/next, position indicators, keyboard support and a visible pause control. Reduced-motion visitors receive no automatic rotation.

SEO and accessibility

The existing Home H1 stays authoritative. Every slide needs descriptive alt text; automatic changes are not repeatedly announced.

Failure and audit

Invalid or off-site paths fail closed. Every save/publish/pause/archive/reorder creates an audit snapshot. Failed writes preserve the last saved state.

Slide editor

Paste an approved same-site path, or choose an image from your computer and it will be uploaded to the approved Devil n Dove public-media bucket automatically.

Saved slides

Lower display-order numbers appear first. Save order after changing ranks.
