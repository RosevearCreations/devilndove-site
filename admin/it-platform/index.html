Next probable major direction

Build 443 candidate — editable Home carousel

This is a candidate until Build 442 reaches a safe checkpoint. The detail below is the delivery contract we will use so “carousel” means a complete operator/public feature, not only moving pictures.

Purpose and ownership

Commerce/merchandising owns approved message, image and destination facts. I.T. owns release health and failure evidence. The carousel highlights current creations, seasonal stories, workshop content or notices without replacing truthful product availability.

Admin editing

Create, preview, reorder, schedule, pause and archive slides. Each slide needs a title, concise body, approved image, descriptive alt text, CTA label/URL, status and sort order. Saving and publishing are separate, audited actions.

Public behavior

Phone/tablet/desktop layout, previous/next controls, position indicators, keyboard operation and a visible pause control. The first approved slide loads promptly; later images are deferred. Important Home text remains available outside rotation.

Safety and fallback

No approved slide, failed API or broken image keeps the existing static Home hero. Invalid/off-site links fail closed. Expired or unapproved slides never render. Admin failures preserve the last saved state and never claim a publish succeeded.

Accessibility and SEO

Respect reduced-motion preferences, pause on focus/hover, announce controls without repeatedly announcing automatic changes, preserve one page H1, prevent layout shift and keep canonical/structured-data facts independent of rotating copy.

Release acceptance

Schema/migration, permission, audit, restore, cache, API-failure and empty-state tests; keyboard/screen-reader/reduced-motion checks; phone/tablet/desktop visual acceptance; LCP/CLS review; exact Development deployment evidence before any Production decision.

Feature-detail rule: every future major feature will show its purpose, owner, operator workflow, public behavior, failure/fallback, permissions, accessibility/SEO impact, data authority and acceptance evidence inside the application.
