ⓘ Where do the prices and actual usage come from?

Actual materials are from already-posted and non-reversed canonical Inventory receipts, valued with today's Inventory item unit cost (an estimate, not a historic purchase-cost claim). Time comes from Work Order entries. Production cost evidence supplies known category totals. Missing costs remain unknown; reserves, BOM plans and Creative Process alternative time logs are never added twice.

ⓘ What does an incomplete total mean?

“Known subtotal” includes only values with evidence. The complete cost remains unknown until every required category is either recorded or deliberately marked zero. A failed batch may carry real cost but no eligible sale. Scrapped material is already part of actual material consumption, not another expense.

ⓘ Why are packaging and rework called fallbacks?

If our Production Cost Evidence already has an amount for one of these categories, that original source wins and this fallback is not added. Rework extras exclude material already consumed and Work Order time already counted. Manually entered machine minutes cannot override recorded Production machine time. Save zero only after verifying none was used.
