ⓘ Shared membership vs physical location

Inventory Workstation Memberships identifies the stations where a Tool can be used. Current Location is an independent physical location pointer. Neither proves it is in stock, on site, calibrated, safe, or available for a time slot.

2. Check the scheduling window

Choose a real Tool, project and window to check recorded conflicts.

ⓘ What does the conflict decision mean?

We must first inspect each overlap and record a specific decision with our reasoning. A second booking never silently overrides another. Maintenance and resource holds cannot be overridden by this workspace. For those, resolve the actual maintenance or choose another time or Tool.

3. Record a human conflict decision

Only active overlapping project bookings may receive a manual overlap approval. The decision is tied to the exact Tool, project, calendar request and UTC window. Once recorded it cannot be edited.

4. Record a real safety inspection or hold

ⓘ Is a passed check the same as automatic release?

No. A checked box and past inspection do not change Tool lifecycle, mark calibration complete, grant future safety, adjust Inventory, or post to Etsy. Use the Tool Lifecycle screen to update true out-of-service and maintenance conditions separately.

5. Confirm and save the actual project booking

ⓘ This never starts a machine or posts a sale

Saving the reviewed booking writes one canonical Production Calendar entry only. It does not complete a traveler step, consume Tool or material stock, sign off an inspection, record labour, create an invoice, or publish to Etsy/Marketplace.
