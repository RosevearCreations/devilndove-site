ⓘ How the metrics and action feedback work

Every tile counts only the newest 100 records in that module—not necessarily its entire history. Truncated modules are clearly marked. Material reservations are not actual consumption; tracked minutes are not payroll; commission review decisions are not confirmed payments. No automation, remote provider write, publication or accounting posting runs from this page.

On Admin pages, explicit save/add/update/delete requests display a waiting state on the initiating button, temporarily disable it, and show a clear success or error acknowledgement. Identical in-flight JSON writes in the same browser page are joined, rather than submitted twice. A lost connection leaves the result unknown: refresh before retrying. Server-side unique request keys and validation remain essential; the browser safeguard cannot prevent repeats from other tabs, devices or manual direct API requests.
