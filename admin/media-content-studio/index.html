How this Studio works

Existing image

The image already in the page is the default. Assigning a new image overrides only that slot.

SVG placeholder

A branded placeholder marks a visual location that still needs a real photo or artwork. Admins can turn on the single page-wide Edit switch on the public page, then choose the exact placeholder to replace.

Use original/default

Removing a Studio assignment immediately returns that location to the authored/default image or text.
