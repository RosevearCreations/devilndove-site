Startup Readiness Guide

Work through these gates in order. A page or feature existing is not proof that it is ready; each gate includes a deployed test and a clear pass condition. The complete detailed document is STARTUP_GO_LIVE_GUIDE.md.

Start here

  1. Back up D1.
  2. Apply the Build 222 migration once.
  3. Deploy the complete package.
  4. Run Deployment Preflight.
  5. Then work from Gate 2 through Gate 20.

Open the full Markdown guide

1. Database and deployment

Cloudflare D1 + Deployment Preflight
Steps
  1. Back up production D1.
  2. Apply database_build222_soap_label_startup_readiness.sql or the current-pass file, not both.
  3. Deploy the full ZIP.
  4. Run and save preflight.

Pass: migration and preflight complete with no critical error.

2. Login and recovery

Login · Forgot password · Admin
Steps
  1. Test login/logout in a private window.
  2. Test reset-link delivery, one-time use and expiry.
  3. Test logout-all sessions.
  4. Confirm non-admin users cannot reach admin APIs.

Pass: no 500s and server-side role enforcement works.

3. Sensitive roles

Members · Inventory · Products
Steps
  1. Limit permanent delete, reversal, accounting export and approval permissions.
  2. Test each with admin and lower privilege.
  3. Confirm audit evidence.

Pass: unauthorized API calls return 401/403.

4. Stripe and webhooks

Cloudflare secrets · Stripe Developers · payment operations
Steps
  1. Use live keys and a signed production webhook.
  2. Place a low-value real order.
  3. Replay the webhook.
  4. Test failed, expired, cancelled and refunded payment.

Pass: settlement occurs once and retries are safe.

5. PayPal decision

Checkout and payment options
Steps
  1. Hide PayPal until live credentials and callbacks are proven.
  2. When enabled, test capture, cancellation and refund.

Pass: PayPal is fully working or not shown.

6. Inventory settlement

Inventory Operations · Orders
Steps
  1. Buy a regular product and a component set.
  2. Confirm exact-once consumption.
  3. Cancel/refund and confirm exact-once restoration.
  4. Run concurrent final-unit checkouts.

Pass: no duplicate movement or oversell.

7. Material lots

Tools & Supplies → Lots
Steps
  1. Enter every separate purchase and cost.
  2. Physically count stock.
  3. Record review before applying totals.
  4. Keep lot choice deliberate until auto FIFO/FEFO is proven.

Pass: each launch material has traceable quantity and cost.

8. Price, specials and tax

Products · Cart · Checkout
Steps
  1. Test each quantity breakpoint.
  2. Test coupon/gift-card interactions.
  3. Verify Canadian tax by supported destination.
  4. Verify refund tax.

Pass: displayed and server-calculated totals match.

9. Shipping and pickup

Checkout · Pickup · policies
Steps
  1. Limit destinations to those you can fulfil.
  2. Test Ontario, other province, PO box and US only if supported.
  3. Verify rate, tax and instructions.

Pass: every accepted address can be fulfilled as promised.

10. Transactional email

Registration · reset · order · refund · fulfilment
Steps
  1. Test every required email.
  2. Check Gmail, Outlook and mobile.
  3. Confirm domain authentication and resend path.

Pass: essential mail arrives and failures are visible.

11. Launch products

Product Release Preflight
Steps
  1. Choose a small launch list.
  2. Complete product facts, price, SKU, stock, dimensions, care and shipping.
  3. Resolve every required preflight issue.

Pass: every opening-day product is green and manually reviewed.

12. Images and rights

Catalog Media · IMAGES_REQUIRED.md
Steps
  1. Add real featured/supporting images.
  2. Set role, order, alt text and rights.
  3. Verify R2 derivatives and fallbacks on weak mobile.

Pass: no placeholder or broken product image remains.

13. Soap labels and print proof

Soap Label Studio
Steps
  1. Enter verified INCI and bilingual rows.
  2. Review claims, warnings, dealer/contact and metric quantity.
  3. Save version, print at 100%, measure and wrap.
  4. Record a passed print test before approval.

Pass: each soap has an approved version and physical proof.

14. Cosmetic notification

Health Canada Cosmetic Notification Form
Steps
  1. Prepare product, manufacturer, contact, use and formula/concentration data.
  2. Submit within the required period after first sale.
  3. Update when the formula/name/business details change.
  4. Retain evidence.

Pass: notification/change control is documented for every cosmetic.

15. Policies

Privacy · Terms · shipping/refund/pickup
Steps
  1. Review business details and effective dates.
  2. Confirm checkout/footer links.
  3. Match policy wording to actual operations.

Pass: customers can find and understand policies before payment.

16. Search and analytics

GA4 · Search Console · Google Business Profile
Steps
  1. Verify analytics once per page.
  2. Submit sitemap and check indexing.
  3. Keep Business Profile accurate.
  4. Use truthful local wording.

Pass: public pages and commerce events are observable without data leakage.

17. SEO, accessibility and devices

Preflight · Lighthouse · real devices
Steps
  1. Confirm one H1, title, meta and canonical.
  2. Validate structured data.
  3. Test keyboard, contrast, zoom and validation.
  4. Test mobile menu, cart and checkout.

Pass: no critical launch-path issue remains.

18. Restore and fallback

D1 backup · R2 · runtime incidents · smoke tests
Steps
  1. Restore backup into a test D1.
  2. Verify data and media.
  3. Simulate API failure and inspect fallback/incident record.
  4. Document rollback owner and steps.

Pass: restore and rollback are proven.

19. Fulfilment rehearsal

Mobile customer order → admin fulfilment → refund rehearsal
Steps
  1. Place and pay a real low-value order.
  2. Pick/make, label, pack and fulfil it.
  3. Confirm accounting/inventory.
  4. Run a separate cancellation/refund.

Pass: no database editing or guesswork is needed.

20. Controlled opening

Small product list · conservative stock · daily monitoring
Steps
  1. Publish only completed products.
  2. Monitor orders, webhooks, email, stock and errors closely.
  3. Add products and channels gradually.

Pass: the store opens with only proven workflows.
