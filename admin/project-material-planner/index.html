Reserve real supplies across projects using one canonical stock identity. Review supplier cost sources and verified posted material consumption without duplicating inventory.

ⓘ Help — reserving, partial consumption & costing

Reservations reduce available stock in the shared Inventory reserved balance, not on-hand quantity. Use stock units for holds. To consume some materials, first release the exact reserved stock units, then record actual partial usage through Creative Process. That existing workflow makes the Inventory posting. This planner does not directly consume materials, place supplier orders, or post accounting entries. Unit costs displayed here are estimates; unpriced materials have unknown, not zero, cost. The reservation and Inventory movement records are auditable.
