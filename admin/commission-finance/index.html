Safety and acceptance boundary

A draft quote is not revenue. A deposit request is not payment. An issued invoice is not cash. A reviewed cost is an estimate until source expense/ledger evidence exists. Actual provider settlement, accountant signoff and Master Shell percentage are not independently verified.

All reads require the original Financials Admin authority, are explicit and private, and exclude names, emails, addresses, tokens, private media and provider reference IDs. No invoice, customer message, tax filing, payroll, ledger, stock, payment or refund write is performed.
