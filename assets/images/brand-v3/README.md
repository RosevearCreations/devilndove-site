# Devil n Dove — brand-v3 artwork directory

This folder contains the approved **Set 1–5 customer-site artwork (01–50)**, the **Set 6 Admin visual concepts (51–60)** and **Set 7 decorative Admin artwork (61–70)** on the `dev` branch.

## File naming
- 01–20 and 31–50: numbered WebP files.
- 21–30: approved *unnumbered* promotional filenames (legacy convention). See `/public/js/brand-v3-auto.js`.
- 51–60: files end in `-CONCEPT.webp`. They are design **references only**. They show illustrative UI and invented example metrics; do not substitute them for real Admin tables or controls.
- 61–70: numbered `.webp` images generated by `/scripts/generate_brand_v3_set07.py`; these are **decorative illustrations**, not interactive screens or representations of real order, inventory, revenue, shipping or account states.

## Integration
The customer site safely preloads 01–50 through `/public/js/brand-v3-auto.js` and displays mapped assets only when available. Do not replace merchant-uploaded product media or owner-customized Media & Content Studio assets.

The Admin image themes and suggested route assignments for Set 7 are documented in `SET07-PLACEMENTS.md`. **Adding the images to this folder alone does not attach them to the corresponding Admin pages.** A separate reviewed UI integration is required. Keep existing Admin forms, real charts, data bindings, authentication and permissions functional.

## Deployment
Images committed to `dev` do not by themselves prove `main` or Cloudflare Production is updated. Promote only after required checks and review; verify deployed file URLs and production status. Do not use placeholder images to imply real stock, fulfillment or provider publication.
