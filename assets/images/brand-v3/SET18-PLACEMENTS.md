## Installed image mapping
- Each Admin HTML page includes `/public/js/admin-brand-v3-set18.js?v=18` and `/css/admin-brand-v3-set18.css?v=18`.
- The loader matches the page route to the exact filename and inserts the banner only after the WebP loads. On a missing file, existing page content remains unchanged.
- CSS uses `object-fit:contain` to avoid cropping the picture or embedded labels. Mobile screens allow horizontal scrolling to read the full-width banner.
- The `public/js/brand-v3-auto.js` manifest also lists 171–180 for consistency.
- Images are illustrative decorative brand scenes. Never replace real product, tool, supply or showcase photos, real prices, Admin figures, controls, rights or logged data.
- Code being on `dev` does not mean the images were uploaded or `main`/Cloudflare Production is GREEN. Check separately.
