# Build 275 Deployment Checklist

1. No D1 migration is required for Build 275.
2. Deploy the Build 275 application package.
3. Hard-refresh `/admin/packaging-studio/` so `styles.css?v=275` and `admin-packaging-studio.js?v=275` load.
4. Open the affected Goat’s Milk soap-label project.
5. If Structured Ingredient Rows are blank, click **Reload from attached base**. If no base is attached, open Material Library, choose the existing Goat’s Milk base and click **Use template / Reapply**.
6. Confirm the structured rows persist after switching tabs and refreshing the page.
7. Click **Draft French** or open French review and click **Translate to French / generate draft**. Review every generated French field before approval.
8. Open Artwork / wording / colours and test the actual-rose quick palette. Confirm the selected rose, bold brand-script soap title and claim-icon spacing in the SVG preview.
9. Save the packaging project and create a review version before physical printing.
10. Perform a 100% physical print test before treating the visual changes as approved production artwork.
