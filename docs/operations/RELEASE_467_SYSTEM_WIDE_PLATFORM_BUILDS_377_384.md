# Devil n Dove — System-Wide Platform Builds 377–384

**Direction:** reusable core application features for every maker project, regardless of the example project chosen. User requested moving beyond Grey Hair and isolated story projects. Build 376 launches the authenticated read-only all-project portfolio at /admin/project-discovery-overview/. Human-controlled evidence, media rights, accounting and approvals stay authoritative; implementation should never fabricate project outcomes or submit providers automatically.

## Build 377 — Multi-Project Portfolio, Workflow & Evidence Routing Foundation
Reusable project lifecycle, configurable categories, linked CAIP evidence and Maker Story completeness, operator navigation and project-aware task routing. Support all active projects; do not hardcode one project's ID. Plan accurate state from authoritative data.

## Build 378 — Cross-Project Workstations, Equipment & Capacity Planner
Model which tools and shared workstations each project requires, simultaneous workstation allocation, resource contention and actual availability; respect existing multi-station tool ownership.

## Build 379 — Work Orders, Task Sequencing & Time Capture
Operator-controlled work plans, status transitions, accountable time logs, milestone evidence and dependencies, with bounded read/write permissions and audit trails.

## Build 380 — Multi-Project Materials, Consumables & Costing
Cross-project raw inventory reservations, usage quantities/units, supplier costs, unique active material identities, partial consumption and job cost rollups.

## Build 381 — Production Calendar, Resource Conflicts & Availability
Resource-backed schedule/calendar for maker work, order deadlines, maintenance and approvals, with conflict detection and manual overrides.

## Build 382 — Customer Requests, Quotes & Commission Lifecycle
Custom order inquiries, quotes, deposits, revision approvals, job handoff and customer-visible progress gates without exposing private operational data.

## Build 383 — Cross-Project Accounting, Revenue & Profitability
Link actual materials, labor, overhead, tax, deposits and payment reconciliation to project profitability and source-of-truth accounting records.

## Build 384 — System-Wide Analytics, Automation & Operational Reliability
Status dashboards, low-cost paginated cross-project reports, auth/role controls, audit history, sustainable D1/Worker budgets and alerting. Any automation needs explicit control, staged validation and rollback.

**Delivery rules:** one GREEN candidate at a time; Development exact-head quality, D1 migration discipline, production matching-tree Pages and live-resource proofs. No hidden free-tier quota growth, automatic story publication, rights inference or unsupported customer/provider action. Titles are a queue; each build requires independent implementation and verification.
