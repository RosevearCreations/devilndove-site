# Release 467 Build 295 — Storefront Buyer Journey Simplification

Build 295 makes the public site behave like a small maker business instead of an operations console.

The three primary paths are **Shop something**, **Ask us to make something**, and **Watch us try something**. Shop now starts simple and moves process-oriented controls behind Advanced filters. Social-readiness, proof-image and sale-channel controls are no longer buyer-facing. Product cards no longer expose social-ready/proof/trust-note implementation labels.

Workshop Follies and Maker Stories reuse the reviewed Workshop Journal / case-study publication path introduced by earlier CAIP and Content Studio work. Private CAIP source media remains private.

Build 295 is schema-neutral. It creates no Product, project, media, publication, provider, payment, D1 business-data or R2 mutation path.
