# Release 467 Build 317 — Third Project Maker Story Readiness & Evidence Selection

Build 317 starts from exact Build 316 Development/Production GREEN.

It remeasures the remaining active Creative Projects that do not already have a Maker Story profile. Selection is deliberately stricter than the earlier metadata-normalization path: **metadata alone is no longer sufficient** for a third Maker Story.

A project is ready only when it already has exactly one CAIP workspace and one Content Studio package and satisfies at least one factual path:

- recorded non-planning execution/result/material/process evidence plus a safe text timeline event; or
- at least two approved CAIP source-evidence ranges, a reviewed/approved story plan, and at least two source-backed story items.

At most one project may be selected. Private CAIP assets do not become public by selection, and public-media rights remain a separate explicit decision.

The initial Build 317 workflow is read-only. If one project qualifies, the same build may add one bounded evidence-selection/profile-adoption step after the exact discovery result is inspected. If none qualifies, Build 317 closes GREEN with no profile/evidence mutation.
