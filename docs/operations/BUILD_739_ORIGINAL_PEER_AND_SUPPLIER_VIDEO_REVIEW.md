## VEVOR / special Tool and Supply reviews
- Existing authenticated `/admin/vendor-reviews/` already stores **Devil n Dove-authored** purchased-item reviews, Tool/Supply Inventory association, manufacture-versus-vendor distinction, verification status and `external_review_url`.
- Build739 provides an operator-facing "Special Tools & Supplies — VEVOR" entry panel and a click-to-load video **preview card** using only allowlisted HTTPS first-party YouTube, Instagram or Facebook public video permalink formats. URL parsing rejects non-HTTPS, credentials, alternate ports and lookalike hosts.
- YouTube embeds use the privacy-enhanced `www.youtube-nocookie.com/embed/` host. Instagram/Facebook use their official platform embed/player endpoints and may be blocked by provider policy, account privacy, authentication, browser CSP or content restrictions; link fallback remains available.
- A player is not instantiated until a signed-in operator presses "Load review video." The review URL remains the existing saved source field; no new database schema or social provider credentials required.
- The card is **Admin preview only**: creating/saving a review does not publish a public product page, place a social mention, claim an affiliate relationship, or contact/tag VEVOR. Only actual received/sampled equipment should be reviewed. Disclose free products/sponsorship/affiliate links when publishing. `https://www.vevor.ca/` is a supplier reference, not endorsement.
