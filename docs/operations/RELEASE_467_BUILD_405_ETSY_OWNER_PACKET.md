## Owner-reported acceptance blocker: Build 399 profile selects empty
The supplied screenshot of Product #54 ("Bar Soap Sweet Orange") shows preflight blocker \`oauth_access_expired_or_near_expiry\`. Build 399 deliberately disables live Etsy taxonomy, shipping and readiness GETs until Etsy OAuth access is current. This is **not** a missing dropdown option bug and **does not** mean a listing was created. The previous OAuth widget hid Connect Etsy when stored connection_status was connected, even if the short-lived access token expired. Build 405 displays a **Reconnect Etsy** action on the existing main-site OAuth widget for expired/near-expired authorization and adds a direct recoverable instruction in Build399. This requires owner reauthorization; there is no unattended credential refresh or fabricated shipping/taxonomy identifiers. After reconnect, choose the draft, recheck readiness, and press **Read live Etsy categories & shipping/processing profiles (GET only)**. If the connected Etsy shop has zero configured shipping or processing profiles, those must be configured in Etsy first.

## One source Product, local destination switches
The Product Editor remains the single canonical source for product title, description, price, quantity and gallery. Build 405 adds independent Etsy and Facebook Marketplace destination **intent** switches to the same Product creation/edit screen, initially OFF when not configured. Save Product first; when the Product save succeeds, marked channel intent is stored in D1 audit history for the saved product ID (or via Save destination choices on an existing Product). These are NOT live publish toggles. They do not duplicate Product entries, images, supplier data, or automatically create provider listings. Existing Build 450 Marketplace export previews derive source data and images from canonical Product/Product Images tables. Subsequent work must honor a source-of-truth channel-intent selector across each channel's full export/publish path before it is safe to use these toggles as actual publication controls.

After Build399–404 manual linked-draft, image, compliance, correction and owner readiness acceptance, select the linked local draft UUID in the Build405 section.
